# Entgeltabrechnung

| Operation | Position auf der Gehaltsabrechnung                                                                             |
| --------- | -------------------------------------------------------------------------------------------------------------- |
| =         | Bruttogehalt                                                                                                   |
| +         | Prämien, Sonderzahlungen (z.B. Provisionen, Urlaubs- oder Weihnachtsgeld)                                      |
| +         | Vermögenswirksame Leistungen                                                                                   |
| =         | Sozialversicherungspflichtiges Entgelt (Grundlage für Kranken-, Pflege-, Renten- und Arbeitslosenversicherung) |
| -         | Steuerfreibetrag                                                                                               |
| =         | Steuerpflichtiges Bruttoentgelt (Grundlage für Lohnsteuer, Solidaritätszuschlag und Kirchensteuer)             |
| -         | Lohnsteuer                                                                                                     |
| -         | Solidaritätszuschlag                                                                                           |
| -         | Kirchensteuer                                                                                                  |
| -         | Krankenversicherung                                                                                            |
| -         | Pflegeversicherung                                                                                             |
| -         | Rentenversicherung                                                                                             |
| -         | Arbeitslosenversicherung                                                                                       |
| =         | Nettoentgelt                                                                                                   |
| -         | Vermögenswirksame Leistungen (Bausparverträge)                                                                 |
| -         | Vorschuss                                                                                                      |
| =         | Auszahlungsbetrag                                                                                              |

Lohnsteuer, Solidaritätszuschlag und Kirchensteuer bemessen sich am steuerpflichtigem Bruttoentgelt und werden vom Arbeitgeber eingehalten und gesammelt bis zum 10. des Folgemonats an das Finanzamt überwiesen.

Sozialversicherungsbeiträge bemessen sich am sozialversicherungspflichtigen Entgelt und werden vom Arbeitgeber gesammelt bis zum drittletzten Bankarbeitstag des jeweilgen Monats an die Krankenkassen überwiesen.

Zusätzliche Sparverträge des Arbeitnehmers umfassen Bausparverträge für welche der Arbeitgeber die Beträge direkt auf das Bausparkonto des Arbeitnehmers überweist.

# Sozialabgaben

Sozialabgaben folgen aus den 5 Säulen der Sozialversicherung. Diese sind die Kranken-, Pflege-, Renten-, Arbeitslosen- und Unfallversicherung.
